Política de privacidad

Matias MKT Lanzador · vigente desde el 4 de octubre de 2026

«Matias MKT Lanzador» es una aplicación interna que usa la API de Marketing de Meta para crear y administrar las campañas publicitarias de las cuentas propias del portafolio «Matias MKT - Portafolio». No es una aplicación pública: no tiene usuarios externos ni inicio de sesión de terceros.

Qué datos usa

Solo datos de las cuentas publicitarias propias del portafolio: campañas, conjuntos, anuncios, piezas creativas y métricas de rendimiento (gasto, impresiones, clics y conversiones agregadas).

Qué datos no recolecta

La aplicación no recolecta, almacena ni procesa datos personales de usuarios de Facebook o Instagram, ni de las personas que ven los anuncios.

Con quién se comparten

Con nadie. Los datos se usan únicamente para operar y medir las campañas propias y no se venden ni se ceden a terceros.

Eliminación de datos

Como la aplicación no guarda datos de usuarios, no hay datos personales para eliminar. Los datos de campañas viven en las cuentas publicitarias de Meta y se administran desde ahí.

Cambios

Si esta política cambia, se actualiza en esta misma página con su nueva fecha de vigencia.
